# Skills

- **notes-to-obsidian** — turns photographed/scanned handwritten study notes into an honest rating, a technique breakdown, and polished Obsidian-ready topic notes.
- **clarify-on-confusion** — makes Claude notice when it may have misunderstood you and ask 1-3 specific questions before continuing.

clarify-on-confusion was created with Claude, directed by Sudip Musib and inspired by Trail of Bits' ask-questions-if-underspecified skill and Clarify-Intent by irfanannaafi19. The wording is original, not copied.

## Install paths

- **Claude Code:** `~/.claude/skills/<name>/`
- **Claude.ai:** zip the skill folder and upload in Settings → Skills
